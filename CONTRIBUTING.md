# Contributing to Python Algorithms

Thank you for your interest in contributing to this repository. This project is maintained as a learning-focused collection of Python algorithm implementations.

## How to contribute

1. Fork the repository.
2. Create a branch with a descriptive name, for example:
   - `feature/merge-sort`
   - `bugfix/median-index`
3. Make your changes in the branch.
4. Add a clear commit message describing the change.
5. Open a pull request against `main`.

## Issue and pull request process

- Open an issue if you find a bug, want a new feature, or need clarification.
- Link issues to pull requests when relevant.
- Include sample input and expected output for algorithm behavior changes.
- Keep changes small and focused.

## Branch naming

Use descriptive branch names such as:
- `feature/<short-description>`
- `bugfix/<short-description>`
- `docs/<short-description>`

## Review expectations

- All contributions should be reviewed before merge.
- Pull requests should explain what changed and why.
- Code should be readable and maintainable.
- If you add or update an algorithm, include usage examples in the README or code comments.

## Testing and quality

- This repository currently uses plain Python scripts.
- Verify your code by running it with Python 3.
- Keep implementations clear and avoid unnecessary complexity.
