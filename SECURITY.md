# Security Policy

## Reporting a vulnerability

If you discover a security issue in this repository, please do one of the following:

- Use GitHub Security Advisories if available.
- Open a private GitHub issue titled `Security: <short description>`.

Do not include exploit details in public issues. Provide enough information for maintainers to reproduce and fix the problem.

## Supported versions

This project is a small Python exercise repository. Security fixes are provided on a best-effort basis.

## Contact

If you cannot use GitHub Security Advisories, contact the repository owner via their GitHub profile.
